# Web App (Next.js)

This directory contains the Next.js frontend used by this repository.

## Important Policy

- Do not start the legacy HTML/Vite frontend under `src/`.
- Use this Next.js app as the frontend during development.

## Start Development Server

Recommended from repository root:

```bash
npm run dev:web
```

Or directly from this directory:

```bash
npm run dev
```

Default URL:

```text
http://localhost:3000
```

## Build and Start

From repository root:

```bash
npm run build:web
```

From this directory:

```bash
npm run build
npm run start
```
