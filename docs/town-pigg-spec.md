# ネオンタウン仕様（アメーバピグ解析と適用）

最終更新: 2026-09-28（アメ・部屋拡張を追加）

## 1. アメーバピグの解析

アメーバピグ（PC版は 2019-12-02 に終了。スマホ版ピグ／ピグパーティ等が後継）の主要な仕組みを整理したもの。

### 1-1. アバター（ピグ）

- 2頭身の大きい頭、正面向き斜め見下ろしの2Dアバター。
- 作成は「顔」→「きせかえ」の2段階。
  - 顔の作成順: りんかく → まゆげ → め → はな → くち → （ほっぺ）→ ひげ。髪型・肌の色も後から変更可能。
  - 人気の傾向: シャープな輪郭、肌色に近いまゆ、ぱっちり目、点の鼻、「3」の口（いわゆる「イケカワ」）。
- きせかえは「1カテゴリ1枠」の重ね着: トップス／ボトムス／ワンピース／くつ／ぼうし／メガネ／首元／背中／手持ち／アクセなど。組み合わせは1兆通り以上。
- 色変更できるパーツと、できないパーツがある。
- 着ている服のセットを「コーデ」として保存できる。

### 1-2. アクション

- 700種類以上。カテゴリは大きく「感情（大笑い・うるうる・ムカッ・ガビーン）」「ダンス」「スポーツ（バク宙など）」「アイテム連動」「季節イベント」。
- 座る・寝るなど「状態」が続くものと、一定時間で終わるものがある。

### 1-3. コミュニケーション

- 吹き出しチャット（頭上に表示）。
- ほかのピグをクリックするとプロフィール。「グッピグ」でほめる（いいね）。
- 友達「ピグとも」、グループ「コミュニティ」。
- カメラ機能（画面の撮影）。

### 1-4. 世界

- 渋谷・原宿・浅草・公園・ビーチなど実在の街を模したエリア。季節ごとに入れ替わる。
- 1エリアには人数上限があり、満員だと別の「チャンネル」に振り分け。
- 各ユーザーが自分の部屋を持ち、家具・壁紙・床で模様替え。友達の部屋を訪問できる。

### 1-5. 経済・遊び

- アメ（ログインや着せ替えで貯まる）、コイン（有料）、ショップで服・家具を購入。
- 釣り、カジノ、庭づくり（ピグライフ）、ペット、スクラッチなど。

## 3. 構成

- ルート: `/` がタウン（入口）。従来のアーケード（対戦ゲーム一覧・ログイン・ルーム）は `/arcade`（＝ゲームセンター）に移動した。タウンのしょうてんがい「ゲーム」店の入口、または画面上部の 🎮 ボタンから入る。`/games/town` も同じ画面（旧URL）。`/arcade?panel=blackjack|poker` で直接ゲームを開ける
- 画面: `apps/web/src/app/games/town/page.tsx`（`app/page.tsx` から再エクスポート）
- アバター
  - パーツ定義: `apps/web/src/games/town/avatar/parts.ts`
  - 描画: `apps/web/src/games/town/avatar/drawAvatar.ts`（合成とアクション）、`avatar/draw/{face,hair,body,items,common}.ts`
  - アクション定義: `apps/web/src/games/town/avatar/actions.ts`
- 世界
  - エリア・経路探索: `apps/web/src/games/town/world/areas.ts`
  - 家具・部屋: `apps/web/src/games/town/world/furniture.ts`
  - 描画: `world/render.ts`（床・壁・並べ替え・吹き出し）、`world/objects.ts`（建物・家具）
- 通信: `apps/web/src/games/town/core/TownGame.ts` ↔ `server/town-world.mjs`（`server/room-server.mjs` に相乗り、`town-*` メッセージのみ処理）
- アメ・持ち物・部屋データ: `server/town-data.mjs` → `server/data/town-data.json`（git 管理外。`TOWN_DATA_PATH` で変更可。旧 `town-rooms.json` は初回起動時に自動移行）
- 値段・確率・部屋サイズ・家具の大きさ: `apps/web/src/games/town/shared/economy.json`（サーバーと画面の両方が読む）
- 目視確認用: `/debug/town-avatars`（全パーツ・全アクション・全家具の一覧）
- ピグとも: `apps/web/src/games/town/friends/cloudFriends.ts`（`/api/friends/*` クライアント。認証情報はアーケードのログインが保存する localStorage を読む）、`components/FriendsPanel.tsx`
- カジノ
  - タウン内: `world/areas.ts` の `casino` エリア（`spots` = 踏むとゲームが開く床）。筐体・卓の描画は `world/objects.ts`（`slotmachine` / `roulettetable` / `cardtable`）。ゲームは `games/casino/components/CasinoOverlay.tsx` がタウンの上に重ねて表示する（`CasinoFrame` の `embedded`）
  - ゲーム: `apps/web/src/games/casino/`（`slots.ts`・`roulette.ts`・`blackjack.ts`・`videoPoker.ts`・`cards.ts` は純ロジック、`bank.ts` が共通コイン）。単体ページは `/games/casino`（ロビー）・`/slots`・`/roulette`・`/blackjack`・`/videopoker`。ゲームセンター側の対戦版は `/arcade?panel=blackjack|poker`
  - ロジック検証: `node scripts/casino-check.mjs`（スロット還元率 約95.2%、ルーレット全ベット 36/37）

## 4. 通信メッセージ（town-*）

| 送信（クライアント → サーバー） | 内容 |
|---|---|
| `town-join` | エリア入室（`area`, `name`, `avatar`, `spawn`, `clientKey`） |
| `town-move` | 目的地タイル |
| `town-chat` | 発言 |
| `town-action` | アクションID |
| `town-goodpigg` | グッピグ（`to`） |
| `town-update` | 名前・アバター更新 |
| `town-room-edit` | 部屋編集（`op`: place / rotate / remove / style / clear）。部屋の持ち主のみ。限定家具は所持が必要 |
| `town-scratch` | スクラッチを買う（結果は `town-scratch`） |
| `town-buy` | 購入（`what`: part / furniture / expand / room） |
| `town-wallet` | アメ・持ち物の再取得 |
| `town-rooms` / `town-areas` | 部屋一覧／エリア人数の取得 |
| `town-where` | ピグともの居場所を問い合わせ（`ids`: フレンドID配列、最大100、3秒に1回）。結果は `town-where`（`found`: `[{friendId, area, channel}]`）。ログインを確認できた人のうち `shareLocation` が true の人だけ返る |
| `town-ping` / `town-leave` | 生存通知／退出 |

- **タウンはログインしたアカウント専用**。`/` を開いたときにログインがなければ `/arcade?reason=town-login`（ログイン画面）へ移動する。ログイン／新規登録に成功すると `/` へ移動する。タウンは開くたびに `town-join` の `area: "home"`（＝自分の自室）で入室する（`?area=casino` などエリア指定があるときだけそのエリア。カジノからの戻りなど）。ゲスト開始ではタウンへ移動せず、ゲームセンター（`/arcade`）だけ遊べる。`?panel=` `?roomCode=` `?inviteToken=` `?from=town` 付きの `/arcade` ではログインしてもタウンへ移動しない（招待・直リンク・タウンからの往復を壊さないため）。
- `town-join` は任意で `auth`（`{userId, password, sessionId}`。アーケードのログインが保存した値）、`shareLocation`（居場所を教えるか。既定 true）、`channel`（ピグともの部屋へ入るときの希望チャンネル。満員なら空いている所）を受け取る。`town-update` でも `shareLocation` を変えられる。
- **ログインの確認**: `auth` があると、ルームサーバーがクラウドAPI（`TOWN_CLOUD_API`、既定 `http://127.0.0.1:8787`）の `/api/auth/ping` でパスワードとセッションを確認する。確認できたときだけ入室でき（アカウント連携・フレンドIDも有効）（確認結果は5分キャッシュ。保存するのはハッシュのみで、パスワードは保存しない）。確認できない・`auth` がないと入室せず `town-error`（`AUTH_FAILED` / `LOGIN_REQUIRED`）を返し、画面はログイン画面（`?reason=town-expired` / `town-login`）へ戻る。同じ接続での失敗が1分に6回を超えると確認をやめる。居場所はエリアとチャンネルのみ。
- 同じブラウザ（`clientKey`）で入り直すと古い接続は退出（`town-replaced`）。
- 45秒以上通信のない接続は自動で退出。
- プレイヤーIDは `clientKey` のハッシュ（1つ目の部屋IDと同じ）。`clientKey` は他人に送られないため、他人が部屋を編集したりアメを使ったりはできない。
- アメの増減・抽選・所持チェックはすべてサーバー側で行う。持っていない限定パーツはサーバーが外してから他の人に配る。
- アメと持ち物はアカウントに保存される（下記「クラウド保存」）。ログイン必須にする前のゲスト記録は、そのブラウザで最初にログインしたアカウントに引き継がれる。

### アメのもらいかた（1日＝日本時間）

| 条件 | アメ | 1日の上限 |
|---|---|---|
| 最初の入室（ログインボーナス） | 30 | 1回 |
| （カジノコイン）最初の入室 | 200 コイン | 1回 |
| 見た目を変えて保存 | 10 | 1回 |
| タウンに5分いる | 5 | 60 |
| グッピグされる | 5 | 50 |
| グッピグする | 2 | 10 |
| 他人のへやに初めて入る | 3 | 15 |

初期値は100アメ。

カジノコインの毎日ログインボーナスは、アカウントごとに1日1回（日本時間0時に切りかわる）。サーバーが「今日はまだ」と判断したときだけ `town-coins`（`delta`, `reason`）を送り、ブラウザが自分のカジノコイン（`neon-casino-shared-bank-v1:<スコープ>`）に加える。コイン自体はブラウザ保存なので、別の端末でその日すでに受け取っていると、この端末には加算されない。値段・量は `economy.json` の `earn.loginCoins`。


### クラウド保存（アカウント連携）

- ログインを確認できた `town-join` は、アカウント（ユーザーIDの小文字）に紐づくプレイヤー記録を使う。アメ・持ち物・へや・グッピグ・名前とアバターが端末をまたいで同じになる。
- そのアカウントで初めて入るときは、そのブラウザの既存の記録（アメ・へや）を引き継ぐ。ただしそのブラウザの記録がすでに別アカウントのものなら、新しい記録を作る。
- （ゲストはタウンに入れないが）アカウントに引き継がれた記録は、`clientKey` だけでは使えない。ログインの確認ができない接続には、その記録を渡さない。
- 名前とアバターはサーバーの保存が優先される。`town-welcome` の `profile` で端末側に反映する。端末に見た目がない場合は `town-profile`（`auth` を送ると `{ok, profile}` を返す）で取得してから入室する。
- 保存先は `server/data/town-data.json`（`players[].cloudKey` と `profile`）。

### 釣り

- ロジック: `apps/web/src/games/town/fishing/reel.ts`（純ロジック。制限時間25秒、開始ゲージ0.3）。画面: `components/FishingPanel.tsx`（タウンのステージ内に表示）。スペースキーでも長押しできる。
- 魚・さお・エサの数値は `shared/economy.json` の `fishing`。さおは当たり範囲（`zone`）とゲージの減りにくさ（`drain`）、エサは珍しい魚の出やすさ（`rare`）と食いつくまでの早さ（`bite`）。エサは1回のキャストで1つ減る。
- 通信: `town-fish-cast`（つり場に立っているときだけ。サーバーが魚を抽選し `castId`・`biteMs`・引きの強さだけを返す）→ `town-fish-result`（`castId`, `caught`, `perfect`）→ `town-fish-caught` / `town-fish-escaped`。食いつき前や釣り上げが早すぎる結果（食いつき後1.5秒未満）は無効。レア以上は同じチャンネルに `town-fish-news`。
- `town-fish-gear`（`rod` / `bait`）で装備を変える。つり場の座標はサーバーの `FISHING_SPOTS` と `areas.ts` の beach の `spots` を合わせること。

### 釣り具屋・景品交換所

- 品物は `economy.json` の `pointShop`（`shop`: fishing / casino）。画面は `components/PointShop.tsx`。ビーチの「つりぐや」、カジノの「けいひん」の前の床、画面上部の 🎣・🪙 から開く。
- `town-shop-buy`（`id`）。釣りポイントはサーバーで引く。**カジノコインはブラウザ保存のため、サーバーが `town-shop-bought` を返したあとブラウザが引く**（ブラウザのデータを書き換えれば無料で手に入る点は、カジノコイン全体と同じ弱点）。持っている服・家具・さおをもう一度買うと `ALREADY_OWNED`。
- ポイントショップの服・乗り物・家具は「限定」扱いで、持っていないと着たり置いたりできない（アメのショップやスクラッチでは出ない）。
- カジノアイテム（`casinoItems`）はサーバーで個数を持ち、ゲーム内で使うと `town-item-use`（`id`, `req`）→ `town-item-used`（`ok`）。タウン内で遊ぶときだけ使える（単体ページには出ない）。
  - フリースピン券: スロットを1回タダで回す（ベット100まで）
  - ほけんチップ: ルーレットで全部はずれたら賭け金の半分がもどる
  - のぞき見メガネ: ブラックジャックでディーラーのふせたカードが見える
  - おかわりドロー券: ビデオポーカーでドロー後にもう1回引きなおせる
- 保存先は `server/data/town-data.json` の `players[]`（`fishPoints`, `fishing`, `fishLog`, `items`）。

### ペットとガーデニング

- 設定は economy.json の pets / garden（クライアントとサーバーが同じファイルを読む）。画面は components/PetPanel.tsx・GardenPanel.tsx・PlotPopup.tsx、ペットの絵は vatar/draw/pet.ts。ヘッダーの 🐾・🌱、街のスポット（petshop / gardenshop）、畑のクリックから開く。
- ペット: 	own-pet-buy|active|rename|pat|feed（返信 	own-pet-done）。なかよし度は0〜100（1日の上限あり）、おなか（hunger）は最後にごはんを食べた時刻から計算。おなかが一定以上空いていないとごはんは受け付けず（NOT_HUNGRY）、食べ物は減らない。つれている子は 	own-member-updated の pet で他の人に伝わり、位置は各クライアントが持ち主に追従させて描く（サーバーには位置を送らない）。

### ボリュームアップ（ミッション・エリア・カジノ・きせかえ）

- **ミッション・じっせき**: `economy.json` の `quests`（毎日プレイヤーごとに3つ、同じ種類は重ならない。全部受け取ると +60 アメ）と `achievements`（22個）。行動はサーバーが数える（`town-data.mjs` の `bump`）。受け取りは `town-mission-claim` / `town-mission-bonus` / `town-ach-claim`（`NOT_READY` なら未達成か受け取りずみ）。画面は `components/MissionPanel.tsx`（ヘッダーの 📋。受け取れる数を赤いバッジで表示）。

### ブロック・かいだん・2階と、模様替えの強化

- **高さのしくみ**: 家具に `z`（何段目にのっているか。0=ゆか）がある。ブロック（`economy.json` の `build.blocks`）は1段ぶんの高さがあり、上に立てる・積める（最大 `rooms.maxLevel` = 3段）。かいだん（`build.stairs`、`dir` で0〜3の向き）は半段ぶんで、ゆか↔ブロックをつなぐ。家具はブロックの上にもおける。**高さ（`z`）はサーバーが決める**（`tileTop` / `autoLevel`。クライアントの `furniture.ts` も同じ規則）。
- **歩き**: ルームに `heights`（立てる高さ）と `tops`（クリックの当たり判定の高さ）を作り、`findPath` は高さの差が半段以内の隣どうしだけをつなぐ。歩くと高さがなめらかに変わる（`TownGame.settleHeight`）。ドア前のマスはどの高さにもおけない。
- **ブロック・かいだんの種類**: ブロック9種（きんのブロック・ネオン・こおりはげんてい）、かいだん4種、てすり、はしら。1マスのものは「はんいでおく」で一気にならべられる。
- **編集ツール**: おく／いどう／まわす（かいだんは4方向、Rキーでも）／いろ／スポイト／かたづける（上のものから）／はんいでおく／はんいでけす（上にのっているものもいっしょに消える）。**もどす・やりなおす**（Ctrl+Z / Ctrl+Y）は部屋のスナップショットを `restore` で送り直す方式（サーバーが持ち物と足場を再チェックし、畑の作物は改ざんできない）。**レイアウト保存**は3スロット（`layout-save` / `layout-load`。かべ・ゆか込み）。
- 通信: `town-room-edit` の `op` は `place` / `remove` / `rotate` / `recolor` / `move` / `fill` / `erase` / `restore` / `layout-save` / `layout-load` / `style` / `clear`。エラーは `HAS_ABOVE`（上にのっている）・`TOO_HIGH`（積みすぎ）など。部屋の上限は 90 / 130 / 180こ。
