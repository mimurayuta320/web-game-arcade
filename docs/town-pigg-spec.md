# ネオンタウン仕様（アメーバピグ解析と適用）

最終更新: 2026-09-28（アメ・部屋拡張を追加）

## 1. アメーバピグの解析

アメーバピグ（PC版は 2019-12-02 に終了。スマホ版ピグ／ピグパーティ等が後継）の主要な仕組みを整理したもの。

### 1-1. アバター（ピグ）

- 2頭身の大きい頭、正面向き斜め見下ろしの2Dアバター。
- 作成は「顔」→「きせかえ」の2段階。
  - 顔の作成順: りんかく → まゆげ → め → はな → くち → （ほっぺ）→ ひげ。髪型・肌の色も後から変更可能。
  - 人気の傾向: シャープな輪郭、肌色に近いまゆ、ぱっちり目、点の鼻、「3」の口（いわゆる「イケカワ」）。
- きせかえは「1カテゴリ1枠」の重ね着: トップス／ボトムス／ワンピース／くつ／ぼうし／メガネ／首元／背中／手持ち／アクセなど。組み合わせは1兆通り以上。
- 色変更できるパーツと、できないパーツがある。
- 着ている服のセットを「コーデ」として保存できる。

### 1-2. アクション

- 700種類以上。カテゴリは大きく「感情（大笑い・うるうる・ムカッ・ガビーン）」「ダンス」「スポーツ（バク宙など）」「アイテム連動」「季節イベント」。
- 座る・寝るなど「状態」が続くものと、一定時間で終わるものがある。

### 1-3. コミュニケーション

- 吹き出しチャット（頭上に表示）。
- ほかのピグをクリックするとプロフィール。「グッピグ」でほめる（いいね）。
- 友達「ピグとも」、グループ「コミュニティ」。
- カメラ機能（画面の撮影）。

### 1-4. 世界

- 渋谷・原宿・浅草・公園・ビーチなど実在の街を模したエリア。季節ごとに入れ替わる。
- 1エリアには人数上限があり、満員だと別の「チャンネル」に振り分け。
- 各ユーザーが自分の部屋を持ち、家具・壁紙・床で模様替え。友達の部屋を訪問できる。

### 1-5. 経済・遊び

- アメ（ログインや着せ替えで貯まる）、コイン（有料）、ショップで服・家具を購入。
- 釣り、カジノ、庭づくり（ピグライフ）、ペット、スクラッチなど。

## 3. 構成

- 画面: `apps/web/src/app/games/town/page.tsx`
- アバター
  - パーツ定義: `apps/web/src/games/town/avatar/parts.ts`
  - 描画: `apps/web/src/games/town/avatar/drawAvatar.ts`（合成とアクション）、`avatar/draw/{face,hair,body,items,common}.ts`
  - アクション定義: `apps/web/src/games/town/avatar/actions.ts`
- 世界
  - エリア・経路探索: `apps/web/src/games/town/world/areas.ts`
  - 家具・部屋: `apps/web/src/games/town/world/furniture.ts`
  - 描画: `world/render.ts`（床・壁・並べ替え・吹き出し）、`world/objects.ts`（建物・家具）
- 通信: `apps/web/src/games/town/core/TownGame.ts` ↔ `server/town-world.mjs`（`server/room-server.mjs` に相乗り、`town-*` メッセージのみ処理）
- アメ・持ち物・部屋データ: `server/town-data.mjs` → `server/data/town-data.json`（git 管理外。`TOWN_DATA_PATH` で変更可。旧 `town-rooms.json` は初回起動時に自動移行）
- 値段・確率・部屋サイズ・家具の大きさ: `apps/web/src/games/town/shared/economy.json`（サーバーと画面の両方が読む）
- 目視確認用: `/debug/town-avatars`（全パーツ・全アクション・全家具の一覧）

## 4. 通信メッセージ（town-*）

| 送信（クライアント → サーバー） | 内容 |
|---|---|
| `town-join` | エリア入室（`area`, `name`, `avatar`, `spawn`, `clientKey`） |
| `town-move` | 目的地タイル |
| `town-chat` | 発言 |
| `town-action` | アクションID |
| `town-goodpigg` | グッピグ（`to`） |
| `town-update` | 名前・アバター更新 |
| `town-room-edit` | 部屋編集（`op`: place / rotate / remove / style / clear）。部屋の持ち主のみ。限定家具は所持が必要 |
| `town-scratch` | スクラッチを買う（結果は `town-scratch`） |
| `town-buy` | 購入（`what`: part / furniture / expand / room） |
| `town-wallet` | アメ・持ち物の再取得 |
| `town-rooms` / `town-areas` | 部屋一覧／エリア人数の取得 |
| `town-ping` / `town-leave` | 生存通知／退出 |

- 同じブラウザ（`clientKey`）で入り直すと古い接続は退出（`town-replaced`）。
- 45秒以上通信のない接続は自動で退出。
- プレイヤーIDは `clientKey` のハッシュ（1つ目の部屋IDと同じ）。`clientKey` は他人に送られないため、他人が部屋を編集したりアメを使ったりはできない。
- アメの増減・抽選・所持チェックはすべてサーバー側で行う。持っていない限定パーツはサーバーが外してから他の人に配る。
- アメと持ち物はブラウザ単位（`clientKey`）で保存される。ブラウザのデータを消すと引き継げない。

### アメのもらいかた（1日＝日本時間）

| 条件 | アメ | 1日の上限 |
|---|---|---|
| 最初の入室（ログインボーナス） | 30 | 1回 |
| 見た目を変えて保存 | 10 | 1回 |
| タウンに5分いる | 5 | 60 |
| グッピグされる | 5 | 50 |
| グッピグする | 2 | 10 |
| 他人のへやに初めて入る | 3 | 15 |

初期値は100アメ。
